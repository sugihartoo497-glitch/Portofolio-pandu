# 🚀 Pandu Arief Hariyanto - Personal Portfolio Website

Modern, clean, futuristic dark-mode portfolio website untuk mahasiswa S1 Ilmu Komputer & Aspiring Software Developer.

---

## 🌟 Tech Stack & Fitur Utama

- **HTML5**: Semantic tags, clean layout structure, fully accessible.
- **CSS3**: Custom CSS variables, subtle glow & glassmorphism, responsive grid & flexbox, futuristic dark theme (`#0a0a0f`) with electric cyan accents (`#00d9ff`).
- **JavaScript (ES6+)**:
  - ✨ Subtitle auto typing animation
  - 📜 Sticky header with glass blur on scroll
  - 🎯 Active navigation item highlighter
  - 📱 Responsive mobile hamburger navigation drawer
  - 👁️ Scroll reveal animation with `IntersectionObserver`
  - 📋 Interactive code snippet copying with toast notification
  - 📩 Contact form validation & mock submission feedback
  - ⬆️ Smooth back-to-top button

---

## ✏️ Panduan Kustomisasi Cepat

- **Ganti Nama & Bio**: Buka `index.html` dan edit bagian Hero Section (`#home`) dan About Section (`#about`).
- **Update Link Sosial Media**: Cari bagian `hero-socials` dan Contact Section (`#contact`), ganti tautan GitHub, LinkedIn, Instagram, dan Email dengan akun asli.
- **Tambah / Edit Project**: Pada section `#projects`, ubah judul, deskripsi, badges teknologi, serta link GitHub dan Live Demo.
- **Ubah Aksen Warna**: Buka `style.css` pada baris `:root` untuk mengganti `--accent-cyan: #00d9ff;` dengan warna favorit Anda.
